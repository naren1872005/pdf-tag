# PDF Auto Remediation (Tagging) Tool
## User Guide

### 1. Activate the Tool

When you open the application for the first time, you must activate the tool.

1. Open the PDF Auto Remediation (Tagging) application.
2. Enter the **Activation Code** that was sent to your registered email address.
3. Submit the activation code.
4. Once the code is successfully verified, the application will be activated.

> **Important:** An active internet connection is required after activation. **Do not turn off the internet while using the application**, as the tool requires an internet connection to perform the automated processing.

---

### 2. Create a New Project

After successful activation:

1. Click **New Project**.
2. A new project will be created.
3. Select and open the PDF document you want to remediate.

#### PDF Page Limit

The **Demo Application supports a maximum of 5 pages per PDF**.

- If your PDF contains **5 pages or fewer**, the complete document will be processed.
- If your PDF contains **more than 5 pages**, the application will automatically use **only the first 5 pages** for processing.

> **Example:** If you upload a 20-page PDF, only pages **1–5** will be processed in the Demo Application.

---

### 3. Select the PDF Type

After uploading the PDF, select the appropriate document type.

#### Digital PDF

Select **Digital** when the PDF contains native, selectable digital text and other native PDF content.

#### Scanned PDF

Select **Scanned** when the PDF consists primarily of scanned pages or image-based content.

> **Important:** Select the correct PDF type before starting the pipeline. The processing method depends on whether the document is a **Digital PDF** or a **Scanned PDF**.

---

### 4. Run the Automation Pipeline

After selecting the appropriate PDF type:

1. Click the **Run Pipeline** button.
2. The application will start the automated PDF remediation/tagging process.
3. The processing will run in the background.
4. You can monitor the current processing status and progress from the **Bottom Panel**.

The pipeline may take some time depending on the document and the processing required.

> **Do not close the application or disconnect from the internet while the pipeline is running.**

---

### 5. Monitor Processing Progress

While the pipeline is running, the **Bottom Panel** displays the processing progress.

You can use this panel to check whether the document is:

- Waiting for processing
- Currently being processed
- Progressing through different stages
- Completed
- Encountering an error

Once the pipeline finishes successfully, the application will display a **completion notification**.

---

### 6. View the Generated Tags

After the pipeline has completed:

1. Check the **Left Side Panel**.
2. The automatically generated PDF tags will be displayed there.
3. Review the generated tags and the document structure.

The tags generated by the automation process can be reviewed within the application.

---

### 7. Stop the Pipeline

If the pipeline takes longer than expected or you need to stop the processing:

1. Click the **Stop Pipeline** option.
2. The currently running pipeline will be stopped.

Use this option only when you want to interrupt the current processing.

---

### 8. Download, Delete, and Close

After processing the document, the application provides the following options:

#### Download

Use **Download** to save the processed/remediated PDF to your system.

#### Delete

Use **Delete** to remove the current project or processed document from the application.

#### Close

Use **Close** to exit the current project and return to the appropriate application screen.

Choose the required option based on what you want to do with the processed document.

---

### 9. Verify and Update Document Properties

The application also provides **Document Properties** where you can review important document metadata.

You can verify:

- **Document Title**
- **Author**

If the information is incorrect or missing, you can update the corresponding fields.

After making the required changes, ensure that the updated document properties are saved as part of the project/document workflow.

---

---

## Important Notes

1. **Internet connection is required during application usage. Do not turn off the internet while the tool is processing.**
2. The **Demo Application processes a maximum of 5 pages**.
3. For PDFs with more than 5 pages, **only the first 5 pages are processed**.
4. Select **Digital** for native digital PDFs.
5. Select **Scanned** for scanned/image-based PDFs.
6. Do not close the application while the pipeline is running.
7. Use **Stop Pipeline** if you need to interrupt a long-running process.
8. Review the generated tags after pipeline completion.
9. Verify the **Document Title** and **Author** in Document Properties and update them when required.
10. Download the final processed PDF after completing your review.
